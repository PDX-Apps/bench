# remix
Build with **[Remix / React Router v7](https://remix.run)** (framework mode) — file routes with server `loader`s + `action`s, `useLoaderData`, nested layouts. Replaces the React routing + data patterns with the loader/action model.

## Install
```bash
npx create-react-router@latest   # or add to an existing app
bench addon add remix && bench rebuild
```
