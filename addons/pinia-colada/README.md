# pinia-colada
Generate Vue data-fetching composables with **[Pinia Colada](https://pinia-colada.esm.dev)** (Vue-native) instead of the base TanStack Query. Replaces the Vue `QUERY-001` data pattern.

## Install
```bash
npm install @pinia/colada
bench addon add /path/to/bench/addons/pinia-colada && bench rebuild
```
