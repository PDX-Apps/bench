# bench-tailwind

Generate Vue/React components styled with **Tailwind CSS v4** (CSS-first config). Appends Tailwind conventions onto the core styling patterns (`STYLE-001`) for both stacks, so generated components use utility classes + `@theme` tokens.

## Install
```bash
npm install tailwindcss @tailwindcss/vite
bench addon add /path/to/bench/addons/bench-tailwind && bench rebuild
```
