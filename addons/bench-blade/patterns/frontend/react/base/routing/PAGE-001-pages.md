# PAGE-001 — Pages (Blade-rendered project)

This project renders UI with **Blade**. Pages are **not** React router pages here.

Build pages as Laravel routes returning Blade views — see the Blade pages pattern
(`BLADE-004-pages`) via `/blade`. To boot a full React SPA from a Blade shell, see
`BLADE-005-spa-handoff`.

React remains available for interactive components mounted into Blade pages (`/react-component`).
