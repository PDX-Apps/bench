# bench-shadcn-vue
Build Vue UIs with **[shadcn-vue](https://www.shadcn-vue.com)** — copy-paste components you own (Reka UI + Tailwind + CVA). Appends conventions onto the Vue component + styling patterns.

## Install
```bash
npx shadcn-vue@latest init
bench addon add /path/to/bench/addons/bench-shadcn-vue && bench rebuild
```
