# bench-nuxt
Build with **[Nuxt](https://nuxt.com)** — file-based routing, SSR-aware `useFetch`/`useAsyncData`, `layouts/`, and `server/api` routes. Replaces the Vue routing + data patterns with Nuxt idioms.

## Install
```bash
npx nuxi@latest init   # or add to an existing app
bench addon add /path/to/bench/addons/bench-nuxt && bench rebuild
```
